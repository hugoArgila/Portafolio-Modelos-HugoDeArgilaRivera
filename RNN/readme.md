# Recurrent Neural Network (RNN)

Una **RNN (Recurrent Neural Network)** es un tipo de red neuronal diseñada para trabajar con datos secuenciales. A diferencia de las redes neuronales tradicionales, las RNN tienen conexiones recurrentes que les permiten **recordar información previa** y usarla para procesar entradas futuras.

## Características principales
- **Memoria**: Las RNN pueden mantener información del contexto anterior gracias a sus bucles internos.
- **Aplicaciones**: Procesamiento de lenguaje natural, reconocimiento de voz, predicción de series temporales, y análisis de secuencias.
- **Entrenamiento**: Utilizan algoritmos como *Backpropagation Through Time (BPTT)* para ajustar los pesos.
- **Variantes**: LSTM (Long Short-Term Memory) y GRU (Gated Recurrent Unit) son extensiones que mejoran la capacidad de manejar dependencias largas.

## Proyectos

### **CodigosPostales**
Este proyecto utiliza una RNN para **predecir códigos postales escritos a mano**, ideal para experimentar con reconocimiento de patrones en secuencias y procesamiento de imágenes convertidas en secuencias.
