# 🌳 Portafolio de Modelos Random Forest

¡Hola! Bienvenido a mi portafolio de modelos de **Random Forest**. Encontrarás una colección de proyectos que demuestran mi experiencia en la creación, entrenamiento y evaluación de modelos de aprendizaje automático, con un enfoque particular en este potente algoritmo.

---

## 📂 Contenido del Repositorio

- **`ModeloTitanic/`**: Esta carpeta contiene un proyecto completo donde se utiliza un modelo de Random Forest para predecir la supervivencia de los pasajeros del Titanic. Dentro, podrás encontrar:
    - Un **notebook de Jupyter** que documenta todo el proceso, desde la limpieza y preprocesamiento de los datos, hasta el entrenamiento del modelo y la evaluación de su rendimiento.
    - Los **conjuntos de datos** originales (`train.csv` y `test.csv`).
    - Un archivo **`requirements.txt`** con todas las librerías necesarias para que puedas ejecutar el proyecto por tu cuenta.

---

## 🛠️ Requisitos e Instalación

Para ejecutar los notebooks y scripts de este repositorio, asegúrate de tener instalado Python 3.x y las librerías listadas en el archivo `requirements.txt`.

Puedes instalar todas las dependencias fácilmente con este comando:

```bash
pip install -r requirements.txt
