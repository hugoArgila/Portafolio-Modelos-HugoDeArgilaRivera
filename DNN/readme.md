# Deep Neural Network (DNN)

Una **DNN (Deep Neural Network)** es un tipo de red neuronal artificial que contiene múltiples capas entre la capa de entrada y la capa de salida. Estas capas intermedias se conocen como **capas ocultas** y permiten que la red aprenda representaciones complejas de los datos.

## Características principales
- **Profundidad**: Incluye varias capas ocultas, lo que le permite modelar relaciones no lineales.
- **Neuronas**: Cada capa está formada por nodos (neuronas) que aplican funciones de activación para transformar los datos.
- **Entrenamiento**: Se basa en algoritmos como *backpropagation* y optimizadores (SGD, Adam) para ajustar los pesos.
- **Aplicaciones**: Visión por computador, procesamiento de lenguaje natural, predicciones, clasificación, etc.

## Proyectos

### **TallaRopa**
Este proyecto trabaja con datos de **ropa y tallas**, ideal para experimentar con modelos que predicen tallas según características del usuario o de la prenda.
